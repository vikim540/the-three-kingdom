# 遊戲設計文件：三國修仙 MVP 任務書摘要

## 一、專案概述
- **遊戲類型**：回合制布陣策略 + 輕度養成（三國 + 修仙）
- **核心體驗**：召喚名將 → 布陣 → 因名將特性產生完全不同的通關方式與收益
- **MVP 範圍**：穿越開場 → 第一次召喚 4 選 1 → 遭遇劫匪關卡（黃忠伏擊 vs 夏侯惇正面硬剛）

## 二、核心機制
1. **8×8 地圖網格**：普通、草叢（伏擊）、障礙
2. **黃忠伏擊路線**：
   - 布陣於草叢，獲得「伏擊」標籤。
   - 主角誘敵，首領進入射程後觸發「猛將一箭」秒殺首領，其餘劫匪 75% 概率潰逃。
   - 獎勵：稀有高階修仙丹藥。
3. **夏侯惇正面路線**：
   - 與主角相鄰獲得「鐵血援護」減傷 aura。
   - 正面全滅 5 名劫匪。
   - 獎勵：完整通用物資、裝備與金幣。
