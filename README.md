# 三國修仙 (The Three Kingdoms Cultivation) - MVP

回合制布陣策略 + 輕度修仙養成 Web 遊戲。

## 快速啟動

```bash
# 1. 安裝依賴
pnpm install

# 2. 啟動開發伺服器
pnpm dev

# 3. 訪問應用
# 開啟瀏覽器訪問 http://localhost:3000
```
