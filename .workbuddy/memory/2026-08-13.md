## 專業評審：《三國修仙》MVP（不修改代碼）
- 產出：`docs/review/professional_review_2026-08-13.md`（遊戲性 + 工程專業度評審 + 開發路線圖 Phase 0~4）。
- 判定：原型處於「可演示、不可玩、不可維護」階段。
- 三大 P0 致命缺陷：
  1. 座標系精神分裂：`BattleUnit.x/y` 同時被當成 0~1 歸一化（渲染/拖拽）與 0~9 網格整數（CombatSystem/AmbushSystem），導致 `isUnitInBush` 永遠比對不上、真·伏擊分支永不觸發。
  2. 雙戰鬥系統打架：`page.tsx` 的 `runBattleLoop`(executeBattleStep, 網格語義) 與 `BattleScene.executeTacticalCombatSequence`(歸一化+statusEffects) 同時寫入同一 store，行為不可預測。
  3. 訂閱/tween/interval 生命週期洩漏（scene.restart 重建訂閱、每幀 rebuild 容器 + repeat:-1 tween）。
- 玩法短板：名將差異只有 2/4 實作（趙雲/郭嘉技能是死配置）、戰鬥中無玩家 agency、地形數值全為死數據、養成/存檔是空殼。
- 路線圖核心：Phase 0 先統一座標模型 + 單一戰鬥真相源（simulation 出事件流、view 只 playback），否則後續擴充皆建在流沙上。
